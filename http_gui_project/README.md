# HTTP-клиент и сервер с GUI на Python

Учебный проект: ручная реализация HTTP/1.x поверх `socket`, GUI на `tkinter`, фоновые потоки и тесты. Готовые HTTP-клиенты и серверные фреймворки (`requests`, `httpx`, Flask, `http.server` и т. п.) не используются.

## Требования
- Python 3.10 или новее
- Для GUI — стандартный `tkinter`
- Для тестов/линтера: `pip install -r requirements.txt`

## Запуск (из корня проекта)
```bash
python -m src.main
```

## Тесты
```bash
python -m unittest discover -s tests -v
# или
pytest tests/ -v
```

## Возможности
- URL-парсер: схема, хост, порт, путь, query; HTTP и HTTPS.
- HTTP-клиент: GET/POST, пользовательские заголовки, таймаут, чтение Content-Length и chunked-ответов.
- Сервер на выбранном порту (по умолчанию 8080), отдельный поток accept и отдельный поток на соединение.
- Маршруты: `GET /`, `POST /echo`, `GET /time`, `GET /headers`, `GET /status/{code}`, неизвестный маршрут — 404, некорректный запрос — 400.
- GUI: вкладки клиента и сервера, фоновые запросы, лог запросов, запуск/остановка сервера.
- Логирование в `http_gui.log`.

## Ручная проверка сервера
Запустите сервер во вкладке GUI, затем в другом терминале:
```bash
curl -v http://127.0.0.1:8080/
curl -v -X POST -H "Content-Type: text/plain" -d "hello" http://127.0.0.1:8080/echo
curl -v http://127.0.0.1:8080/time
curl -v http://127.0.0.1:8080/headers
curl -v http://127.0.0.1:8080/status/418
curl -v http://127.0.0.1:8080/nonexistent
```

## Архитектура
Подробности, PlantUML и план скриншотов находятся в `docs/`. В проекте определены интерфейсы `HttpTransport`, `RouterInterface` и `ServerInterface` (ABC), а также классы модели `Url`, `Request`, `Response`, `Parser`, `Serializer`, `Socket`, `TcpClient`, `HttpClient`, `Router`, `HttpServer` и GUI-компоненты.

## Ограничения и безопасность
Учебная реализация ограничивает заголовки 8 КБ, тело запроса 10 МБ и ответ клиента 20 МБ. Сервер по умолчанию слушает только `127.0.0.1`; не выставляйте его в публичную сеть без дополнительного аудита. Keep-alive сервера намеренно не реализован: ответ закрывает соединение. HTTPS поддержан на клиентской стороне.

## Загрузка на GitHub через сайт
1. Создайте новый репозиторий на GitHub (например, `http-client-server-python`).
2. Не добавляйте автоматически README или лицензию, если собираетесь загружать эту папку целиком.
3. Откройте репозиторий → `Add file` → `Upload files`.
4. Откройте папку `http_gui_project` на компьютере и перетащите её содержимое в окно загрузки GitHub. Если браузер не принимает папки, загрузите ZIP-архив проекта или выберите файлы и папки по отдельности; ZIP GitHub не распаковывает автоматически.
5. В поле сообщения коммита напишите `Добавлен заключительный проект HTTP-клиента и сервера` и нажмите `Commit changes`.
